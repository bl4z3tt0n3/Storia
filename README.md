# Storia

Questo repository contiene materiali da usare come fonte per rispondere a domande di Storia tramite AI.

## Scopo del repository

Lo scopo di questo repository è raccogliere file, documenti e materiali utili affinché l'AI possa consultarli e rispondere basandosi esclusivamente o principalmente sui contenuti presenti qui.

Il repository è organizzato attorno a un **manuale di storia** (diviso per capitoli), corredato dai relativi **documenti storici primari** e dai **riassunti per capitolo**.

## Come usare questo repository

Quando analizzi questo repository:

1. Leggi prima questo README.
2. Usa i file del repository come fonte principale.
3. Se una risposta riguarda un documento specifico, fai riferimento al file da cui hai preso l'informazione.
4. Non inventare informazioni non presenti nei file.
5. Se un'informazione non è presente, dillo chiaramente.
6. Dai priorità ai file più aggiornati o più completi.

## Struttura del repository

- `/libro/`  
  Contiene i capitoli del libro in forma testuale. Ogni file corrisponde a un capitolo e segue la denominazione `cap_XX_titolo.md` (es. `cap_01_introduzione.md`).

- `/riassunti/`  
  Contiene i riassunti dei singoli capitoli del libro. I file seguono la stessa numerazione della cartella `/libro/` per facilitare il confronto diretto (es. `riassunto_cap_01.md`).

- `/documenti_storici/`  
  Contiene documenti primari, fonti storiche, testi originali o estratti utili a contestualizzare il libro. Ogni file indica chiaramente la fonte e la data del documento.

- `/immagini/`  
  Contiene immagini, mappe, tavole o scansioni utili alla comprensione dei contenuti.

## Ordine consigliato di lettura

Per rispondere alle domande, l'AI dovrebbe consultare i materiali in questo ordine:

1. Riassunto del capitolo pertinente (in `/riassunti/`).
2. Testo integrale del capitolo (in `/libro/`), se serve maggiore dettaglio.
3. Documenti storici correlati (in `/documenti_storici/`), per il contesto primario.
4. Immagini o materiali visivi (in `/immagini/`), solo se necessari.

## Regole per l'AI

L'AI deve:

- basarsi sui contenuti presenti nel repository;
- distinguere tra informazioni certe (presenti nei testi) e interpretazioni;
- citare o indicare il file usato quando possibile, specificando anche il capitolo di riferimento;
- segnalare eventuali contraddizioni tra i file o tra il testo del libro e i documenti storici;
- non usare informazioni esterne, salvo richiesta esplicita;
- rispondere in modo chiaro, ordinato e utile allo studio, contestualizzando sempre i fatti nel loro periodo storico;
- se un capitolo o un documento non è presente nel repository, segnalarlo esplicitamente.

## Note sui file

I capitoli del manuale e i riassunti devono essere numerati in modo coerente. I documenti storici devono riportare: autore o fonte originale, data di produzione, contesto storico di riferimento. Se alcuni file risultano incompleti o poco leggibili, l'AI deve segnalarlo invece di dedurre informazioni non sicure.
